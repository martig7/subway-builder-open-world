## Findings and limitations

1. **Generator defect, fixed:** planar distances diverged from the native speed
   cache by as much as 11.2 meters and caused repeated speed-limit warnings.
   Geodesic lengths removed all measured discrepancies. Zero new speed-limit
   warnings appeared during the corrected follow-up. The repair reset live
   trains and in-flight commute state; lifetime riders and financial totals were
   retained. Native scheduling rebuilt the fleet before the final save.
2. **Recovery issue:** the first imported candidate produced a blank renderer.
   A fresh diagnostic instance loaded it. Running alongside the leftover old
   instance produced IndexedDB `UnknownError: Internal error` during mod startup;
   closing both and starting a single instance resolved it. This does not prove
   a save-format or mod-only crash. The old blank process had no renderer child
   when inspected.
3. **Existing native save-list issue:** schema fallback errors named three older
   files (`khs-seed33-most-stations`, `khs-seed8-episode-export`, and
   `pr-seed40000096-r3-most-stations`), not the generated Japan saves. Their auxiliary
   JSON began with null bytes. They were not modified.
4. **Unrelated runtime errors:** telemetry HTTP 400 failures and an unregistered
   `backup-all-saves` IPC handler appeared. No claim of mod ownership is made.
5. **UI observation:** the in-game save list wrapped long names one character
   per line, while the main-menu save browser displayed normal cards. Attribution
   to the mod is unproven.

No shared runtime source was changed, rebuilt or installed. The session provides
a working load/stress/save fixture and performance targets, not proof of general
mod stability under every world or long-running save.

## Reproduction and evidence

Use `build-japan-stress-save.py --help` with the known eight-station template,
installed city-data root and installed Japan bundle. Import through the native
Import Save File button. Run `python recovery/test-metro-distance.py` for the
distance regression checks. `repair-metro-distances.py --help` documents the
separate-output repair path.

With a single game instance started using loopback debugging port 9222,
`node recovery/cdp-eval.mjs recovery/japan-stress-metrics-expression.js` captures
bounded metrics. Enable/reset simulation diagnostics before sampling. Never dump
the full `latestAuthoritativeLoad.runtimeView`: it contains the whole network.

`stress-transition-*.json` files, `japan-final-verification.json`, and screenshots
