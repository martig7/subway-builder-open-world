# Japan open-world demand: official source inventory

## Decision

Use the 2020 Census **municipality OD table** as the observed national commute/school-flow backbone. Use Census small-area or mesh counts plus building/land-use sources only to *allocate* those zonal totals inside a municipality. They do not reveal a finer observed OD matrix.

**e-Stat does not expose building-to-building OD.** Its finest nationwide named origin-and-destination table is municipality-to-municipality. The small-area product is a town/chome (町丁・字等) table with *destination categories*, while the mesh product gives local counts such as “works/studies in own municipality”, “other municipality in prefecture”, and “other prefecture”—not a paired destination zone. Therefore any town-, mesh-, or building-level OD created from these data is a synthetic disaggregation and must be labelled as modelled, not observed. This conclusion follows the published table scopes and item lists: [Census Table 6-1](https://www.e-stat.go.jp/dbview?sid=0003454527), [small-area Table 16-1 example](https://www.e-stat.go.jp/stat-search/files?cycle=0&data=1&layout=datalist&metadata=1&page=1&stat_infid=000032226842&tclass1=000001136472&tclass2=000001159886&tclass3val=0&toukei=00200521&toukei_kind=6&tstat=000001136464), and the [2020 mesh item list](https://www.stat.go.jp/data/mesh/pdf/r2kokusei.pdf).

## Recommended lawful model hierarchy

1. Download Table 6-2 and 6-3 (or 6-1 if one combined flow layer is enough) and keep municipality codes. This preserves intra-prefecture and cross-prefecture flows in one consistent official source.
2. Build municipality-to-municipality OD matrices first. Aggregate those codes to the selected prefecture blocks only after validation; do not start from Table 5 unless the mod truly needs no municipality structure.
3. Allocate each origin municipality to 250 m Census meshes or town/chome zones, then to GSI/PLATEAU buildings using explicit residential weights. Allocate each destination municipality to Economic Census meshes and then candidate buildings; allocate school flows to P29 points/catchments.
4. Preserve three independent labels in the derived data: `observed_municipality_od`, `allocation_weight_source`, and `synthetic_building_od`. The final label prevents treating a modelled building pair as a released government observation.

## Licence, format and publication cautions

- **e-Stat/Census:** the e-Stat terms allow copying, redistribution, adaptation and commercial use with source attribution; numerical data/simple tables are stated not to be copyright subject. Attribute the source and state processing for derivatives. [e-Stat terms](https://www.e-stat.go.jp/terms-of-use)
- **National Land Numerical Information / P29:** use the individual dataset’s licence shown on its page. The current service terms are based on PDL 1.0; source and processing must be stated, but an individual dataset can impose a different rule. [MLIT licence terms](https://nlftp.mlit.go.jp/ksj/other/agreement.html), [FAQ](https://nlftp.mlit.go.jp/ksj/other/faq.html)
- **PLATEAU:** open licensing permits free/commercial use with attribution, but individual 3D-model datasets may have local-government copyright/source conditions. [PLATEAU site policy](https://www.mlit.go.jp/plateau/site-policy/), [licensing FAQ](https://www.mlit.go.jp/plateau/faq/)
- **GSI Fundamental Geospatial Data:** this is a basic-survey result. It is free to download, but the GSI explicitly says that copying/using it can require Survey Act approval; the exact need depends on the intended use. Confirm through GSI’s use-procedure navigator before shipping it in a mod. [GSI download terms](https://service.gsi.go.jp/kiban/app/help/), [use-procedure guidance](https://www.gsi.go.jp/LAW/2930-index.html)
- **Format:** e-Stat table downloads are Excel/CSV and API JSON/CSV/XML; small-area tables are many prefecture files. GSI uses JPGIS/GML (its viewer can convert non-DEM layers to Shapefile); PLATEAU is principally CityGML; NLI supplies GML and Shapefile. Keep original archives/metadata and source dates.
